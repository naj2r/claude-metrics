TITLE
      'SORTOBS': module to sort observations according to a specified order

DESCRIPTION/AUTHOR(S)
      
       sortobs allows the user to sort observations by either (1) a
      variable's specific values or (2) observation numbers.
      Observations that are not specified in the command retain their
      original, respective sort orders.
      
      KW: data management
      KW: sort
      
      Requires: Stata version 8.2
