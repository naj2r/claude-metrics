| File | Source | Notes |

Other Stata manuals (`d.pdf`, `r1.pdf`, `r2.pdf`, `p.pdf`, `m.pdf`, `xt.pdf`, `ts.pdf`, `svy.pdf`, etc.) are referenced by the install path `C:\Program Files\StataNow19\docs\` and are **not copied** into this directory. The `docs-reader` skill extracts them on demand into `pdfs/<manual>_text.md`.

If the install path is unavailable (Mac/Linux coauthor without Stata's full manuals installed), Claude falls back to `mcp__stata__get_help` and logs the gap to `.claude/UPGRADE_LOG.md`.

## Escalation chain reminder

When stuck on a Stata question:
1. `mcp__stata__get_help <command>`
2. `.claude/rules/stata-gotchas.md`
3. `guides/sources/stata-skill-ref/reference/<topic>.md` (this directory)
4. `guides/sources/pdfs/<manual>_text.md` (if exists)
5. Invoke `docs-reader` skill to generate the extract
6. Other Stata PDFs at `C:\Program Files\StataNow19\docs`
7. Log to `.claude/UPGRADE_LOG.md`

See [CLAUDE.md](../../CLAUDE.md) at repo root for the full convention reference.
